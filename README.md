# Ikrom Shashlik — сайт ресторана

Одностраничный сайт: меню с фильтрами, корзина и оформление заказа.
React + TypeScript + Vite + Tailwind CSS + Lucide. Бэкенда нет.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # проверка типов + сборка в dist/
npm run preview    # просмотр собранной версии
```

## Что нужно заполнить

| Что | Где |
| --- | --- |
| Адрес, телефон, часы работы, Instagram, Telegram, ссылки на карту | `src/config/site.ts` → `contacts` |
| Стоимость доставки | `src/config/site.ts` → `deliveryFee` |
| Блюда, описания, цены (сейчас примерные) | `src/data/menu.ts` |
| Фотографии (сейчас временные, с Wikimedia Commons) | `src/assets/images/`, авторы — `src/data/photoCredits.ts` |
| Тексты интерфейса | `src/i18n/ru.ts` |
| Логотип и фавикон | `src/assets/images/logo.jpg`, `public/favicon.png`, `public/apple-touch-icon.png` |

Пока контакт равен `null`, на сайте стоит пометка «будет указано», а кнопки
«Позвонить» и «Открыть карту» неактивны. После заполнения они включаются сами.

## Заказы

Сайт никуда не отправляет заказ, пока не задан `VITE_ORDER_ENDPOINT` (см. `.env.example`).
Без него гость видит «Заказ сформирован, но не отправлен» и может скопировать текст заказа
(а при заполненных контактах — написать в Telegram или позвонить).

Подключение — в одном месте: `src/lib/order.ts`. Токен Telegram-бота нельзя класть
во фронтенд: нужен небольшой серверный посредник или готовый сервис приёма заказов.

## Узбекский язык

Инструкция из четырёх шагов — в комментарии в `src/i18n/index.tsx`.

## Фотографии

Временные фото распространяются по лицензиям CC BY / CC BY-SA / CC0; авторы перечислены
в подвале сайта («Авторы фотографий»). При замене на собственные снимки очистите
`src/data/photoCredits.ts`. Каждому фото нужны два размера (см. `src/data/menu.ts`).
